## Project Description

A simple responsive personal portfolio website built as the starting point of my professional portfolio. This site is made using HTML for structuring, CSS for styling using flexboxes, media queries, etc., and JavaScript for dynamic time of the day based greetings and form validation. It includes three core sections: about me, projects, and a contact form.

## Setup Instructions (How to Run Locally)

- Clone or download this repository to your computer.
- Locate the index.html file in the project folder.
- Double-click index.html or right-click and open it with any web browser (Google Chrome, Microsoft Edge, Mozilla Firefox).
- No external packages, installations, or local servers are required.
